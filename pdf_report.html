1. Kis File Me Kya Changes Huye H (File-by-File Breakdown)

Har file me jo bhi naya code, naye components ya features add kiye gaye hain, unka complete vivaran niche diya gaya hai:

1. store-data.js Database & Data Layer
  • STORAGE_KEYS.BANNERS ("pretute_db_banners"): Naya storage key banaya gaya taaki homepage sliders ka data localStorage me permanently save ho sake.
  • DEFAULT_BANNERS Array: 3 seed hero slides banayi gayi jisme headline, subtitle, order, active status, image, buttons (text aur link), aur description store hota hai.
  • Banners CRUD Functions: StoreData.getBanners(), StoreData.getBannerById(id), StoreData.saveBanner(data), StoreData.deleteBanner(id), aur StoreData.toggleBannerStatus(id) add kiya gaya.
  • Product Inventory Fields: StoreData.getProducts() aur saveProduct() me stockStatus ("in_stock", "out_of_stock", "on_backorder"), availability ("available", "unavailable"), aur status ("active", "deactivated") ko support aur normalize kiya gaya.
  • Category Attributes: StoreData.getCategories() aur saveCategory() me status, availability, aur showOnHome boolean flag add kiya gaya.
  • Coupon Expiry Engine: StoreData.getCoupons() me real-time date check lagaya gaya — agar coupon ki expiryDate aaj ki date se pehle ki hai toh automatically status = "expired" aur isExpired = true mark ho jata hai. Seed data me EXPIRED50 coupon testing ke liye add kiya gaya.
  • Quick Toggle Helpers: toggleProductStatus(), toggleProductStock(), toggleCategoryStatus(), toggleCouponStatus() add kiye gaye.
Sir ko kya batana hai: "Sir, store-data.js hamari main database file hai. Isme humne Banners ka pura data storage system banaya, Products me stock aur visibility ke new fields dale, Categories me active/deactive aur coupons me automatic expiry date check engine set kar diya hai."

7. app.js Storefront Engine & Sync
  • renderHeroBanners() Function: StoreData.getBanners() se live active banners ko load karke storefront ke main hero slider me render karta hai. Agar admin ne order badla ya naya banner add kiya, toh bina page reload kiye turant reflect ho jata hai.
  • Deactivated Products Protection: renderHomeProducts(), renderCategoryView(), handleSearchQuery(), aur searchSuggestions — sabhi jagah se status === "deactivated" wale products ko hide kar diya gaya hai. Agar koi direct URL #product/1 khole jo deactivated hai, toh alert dekar homepage par redirect kar deta hai.
  • Out-of-Stock & Unavailable Enforcement: createProductCard(), renderProductDetails(), aur openQuickViewModal() me:
    • Agar product Out of Stock ya Unavailable hai toh Red/Grey badge lagta hai.
    • "Add to Bag" aur "Buy Now" buttons disable ho jate hain aur text badalkar "Out of Stock" ya "Unavailable" ho jata hai.
    • Click karne par warning toast notification aata hai.
  • Deactivated Categories Filtering: renderWordPressCategories() me status !== "deactivated" && showOnHome !== false ka filter lagaya gaya hai.
  • Coupon Expiry Checkout Validation: setupPromoApplication() me coupon apply karte waqt check hota hai — agar coupon expired hai (jaise EXPIRED50) toh message aata hai: "Coupon 'EXPIRED50' has expired (1 Aug 2026)." aur discount apply nahi hota.
  • Cross-Tab Live Sync: pretute_data_sync event listener me banners, products, categories, aur settings sabhi views ko instantly update kiya gaya hai.
Sir ko kya batana hai: "Sir, app.js website ka main customer-facing engine hai. Admin panel me aap jo bhi banner badloge, product ko out-of-stock ya deactivate karoge, ya coupon expire hoga — uska turant real-time effect customer side par bina refresh kiye padega."
