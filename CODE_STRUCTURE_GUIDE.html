7. क्विक चीट शीट: "मुझे X बदलना है, तो मैं कहाँ जाऊं?"

काम (Task) कौन सी फ़ाइल खोलें? क्या करें?
वेबसाइट का रंग (Color) बदलना frontend/src/style.css सर्च करें --color-primary और #FF5B7F को अपने मनपसंद हेक्स कोड से बदलें।
10 सेकंड वाले लॉगिन पॉपअप का टाइम बदलना frontend/src/App.jsx लाइन 63 पर जाएं: 10000 को 5000 (5 सेकंड) या जो चाहें कर दें।
एडमिन का पासवर्ड / PIN बदलना backend/routes/admin.js यहाँ 2570 को अपने 4-डिजिट PIN में बदलें।
नया प्रोडक्ट सीधे डेटाबेस में डालना backend/data/products.json सबसे ऊपर नया प्रोडक्ट JSON जोड़ें।
'Our Latest Products' की हेडिंग बदलना frontend/src/components/home/LatestProducts.jsx यहाँ हेडिंग या सब-हेडिंग का टेक्स्ट बदलें।
फ़ुटर का फोन नंबर या पता बदलना frontend/src/components/common/Footer.jsx यहाँ फोन, ईमेल, पता और सोशल मीडिया लिंक्स बदलें।
