## 🚀 How Sir / Store Owner Can Access & Manage The Back Panel

Sir can access the Admin Back Panel using any of the following **4 discreet methods**:

### 1. 🌐 Direct Dedicated URL (Recommended for Bookmarking)
Open the admin page directly in any web browser:
* **Local Development Server**:
  `http://127.0.0.1:8080/admin.html` or `http://localhost:5500/admin.html`
* **Live GitHub Pages URL**:
  `https://mitalee2570.github.io/PRETUTE-Premium-E-Commerce-Platform/admin.html`
* **Direct File**:
  Open `admin.html` in your browser.

> 💡 *Tip: Sir can bookmark this URL in Chrome, Edge, Safari, or add it as a shortcut to their mobile home screen.*

---

### 2. ⌨️ Secret Keyboard Shortcut (From Anywhere on Storefront)
While viewing any page on the website ([index.html](index.html)), simply press:
* **Windows / Linux**: `Ctrl` + `Shift` + `A` (or `Alt` + `Shift` + `A`)
* **Mac**: `Cmd` + `Shift` + `A`

The website will immediately redirect to the Admin Back Panel.

---

### 3. 🔗 Secret Hash Route
In the browser's address bar, add `#admin` at the end of the URL and press Enter:
* Example: `https://mitalee2570.github.io/PRETUTE-Premium-E-Commerce-Platform/#admin`
* Example: `http://127.0.0.1:8080/#admin`

The router will automatically open `admin.html`.

---

### 4. 🖱️ Stealth Triple-Click on Footer Copyright
Scroll to the very bottom of the storefront and **triple-click (click 3 times quickly)** on the copyright text:
`© 2026 PRETUTE Premium Store. All rights reserved.`

It will instantly open the Admin Back Panel. Regular visitors will never know this shortcut exists!

## 🛠️ Key Capabilities in the Back Panel (`admin.html`)

1. **Dashboard Overview**:
   - Total Revenue, total orders, live inventory counts, and visitor inquiries.
2. **Homepage Banners**:
   - Add new promotional slides, edit banner titles/images, or delete old ones.
3. **Products Catalog**:
   - Add new items with image, price, discount, and category.
   - Live status toggles: **In Stock**, **Low Stock**, **Out of Stock**, or **Deactivated** (hide from storefront without deleting).
4. **Categories Management**:
   - Manage baby fashion, toys, maternity wear, gear, etc.
5. **Customer Orders**:
   - View placed orders, customer delivery addresses, and change status (`Pending`, `Processing`, `Delivered`, `Cancelled`).
6. **Discount Coupons**:
   - Create and edit promotion codes (`PRETUTE20`, `GEAR25`, etc.).
7. **Customer Messages**:
   - Review incoming messages sent through the Contact Us form.
8. **Store Settings & Data Backup**:
   - Export full store JSON backup file and restore anytime.
